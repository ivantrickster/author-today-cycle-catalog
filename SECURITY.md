# Безопасность

Расширение работает только с открытыми данными Author.Today и локальным хранилищем браузера. Оно не должно получать пароли, cookies, платёжные данные или тексты произведений.

Если вы обнаружили проблему безопасности, не публикуйте в открытой задаче секреты, данные аккаунта или подробности, позволяющие немедленно эксплуатировать уязвимость. Создайте краткую задачу без чувствительных данных, чтобы согласовать безопасный канал связи с сопровождающим проекта.
