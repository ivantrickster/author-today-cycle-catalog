# Перекалибровка рейтинга

Инструменты воспроизводят модель накопленного риска на более крупной выборке, не включая массовую выгрузку Author.Today в репозиторий.

## Сбор

Требуется Node.js 20 или новее:

```bash
node calibration/collect.mjs --target 1000
```

По умолчанию запросы выполняются последовательно с интервалом не меньше одной секунды. Прогресс сохраняется в `.calibration-data`; повторный запуск продолжает работу с чекпоинта. При HTTP 403/429 или CAPTCHA сбор прекращается на 24 часа.

Цель `--target 1000` означает тысячу завершённых циклов, прошедших базовые правила состава, хронологии и минимального числа томов. Отдельные модели получают меньше наблюдений из-за требований зрелости и наличия метрик.

Контрольная и актуальная когорты собираются в разные каталоги. Актуальная когорта включает продолжающиеся циклы минимум с тремя пригодными завершёнными томами и циклы, завершённые за последние 12 месяцев. Незавершённый текущий том не участвует в её метриках:

```bash
node calibration/collect.mjs --cohort completed --target 1000 --out .calibration-completed
node calibration/collect.mjs --cohort current --target 1000 --recentMonths 12 --out .calibration-current
```

## Обучение

```bash
node calibration/fit.mjs
```

Для актуальной когорты используются только завершённые тома. Основной отчёт описывает текущий снимок рынка, а вариант с прежним шестимесячным порогом служит проверкой чувствительности:

```bash
node calibration/fit.mjs --input .calibration-current/cycles.ndjson --scoreSet finished --maturity 0 --output .calibration-current/model-current.json
node calibration/fit.mjs --input .calibration-current/cycles.ndjson --scoreSet finished --maturity 6 --output .calibration-current/model-mature-6m.json
```

Скрипт формирует `model-report.json` и `model-report.md`, отдельно для аудитории/лайков и расчёта от первого/второго тома. Используются Huber IRLS без свободного члена, пятиблочная валидация с разделением по `seriesId` и групповой bootstrap-интервал коэффициентов.

Коэффициенты нельзя переносить в расширение автоматически. Сначала нужно сравнить CV MAE, доверительные интервалы, распределение рейтингов и изменения баллов относительно предыдущей модели.
