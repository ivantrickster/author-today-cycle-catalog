# Как предложить изменение

Спасибо за интерес к проекту. Перед созданием задачи проверьте, нет ли уже похожего обсуждения.

## Сообщение об ошибке

Укажите:

- версию расширения и браузера;
- ссылку на публичную страницу цикла или тома, если она нужна для воспроизведения;
- последовательность действий;
- ожидаемый и фактический результат;
- снимок экрана без личных данных, если он помогает понять проблему.

Не публикуйте cookies, токены, данные аккаунта, платные тексты произведений и другие закрытые сведения.

## Изменение кода

1. Создайте отдельную ветку.
2. Внесите минимальное изменение с понятным назначением.
3. Выполните `npm test`.
4. Для изменений парсинга при необходимости отдельно выполните `npm run test:integration`.
5. Опишите в pull request, что изменилось и как это проверено.

Сетевые тесты обращаются к Author.Today. Не запускайте их массово или в цикле.
